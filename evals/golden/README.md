# Golden evaluation cases

3–5 hand-checked cases measuring extraction accuracy against public 10-K
filings. Each case records:

- Filing (company, period, EDGAR URL)
- Expected line items (hand-verified values)
- What the extractor produced
- Pass/fail per line item, plus notes on misses
